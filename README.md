# AI Expense Tracker

A Flutter application for tracking expenses.

## Getting started

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. From the project directory, fetch dependencies:

   ```sh
   flutter pub get
   ```

3. Run the app on a connected device or emulator:

   ```sh
   flutter run
   ```

## Project checks

Run the analyzer and tests with:

```sh
flutter analyze
flutter test
```

## Continuous integration

GitHub Actions runs `flutter analyze` and `flutter test` for pushes and pull
requests targeting `main`.
